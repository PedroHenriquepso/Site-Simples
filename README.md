# 🛒 Site Simples — Loja de Informática

Página de uma loja de informática com produtos em promoção, criada para praticar HTML e CSS.

## ✨ O que tem na página

- Título e divisão por categoria (Informática)
- Cards de produto com imagem, descrição, preço e botão de compra
- Ícone personalizado na aba do navegador

## 🛠️ Tecnologias

- HTML5
- CSS3

## ▶️ Como executar

Baixe o projeto e abra o `index.html` no navegador.

```bash
git clone https://github.com/PedroHenriquepso/Site-Simples.git
```
